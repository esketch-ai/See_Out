# Quote Diagnostics & OCR Calculator Engine
Status: Completed
Assignee: @최진호_박사

## Overview
기존 대형 선불식 상조 가입자의 증서를 비전 OCR로 자동 분석하여, 공정거래위원회 표준약관 고시 기준 해약환급금과 현장 추가금을 연산하고 배웅의 실비 패키지와 대조하는 1:1 맞춤 영수증 손익 진단 엔진 설계.

## Key Deliverables
- [x] Task 1: 비정형 상조 계약 증서 Vision OCR 데이터 추출 모델 정의 (계약일, 상품명, 회차, 납입금)
- [x] Task 2: 공정거래위원회 고시 선불식 할부계약 해약환급금 법정 산식 엔진 구현
- [x] Task 3: 현장 숨은 추가금(수의/관 업셀링, 제단 꽃장식, 차량 거리) 추정 알고리즘 수립
- [x] Task 4: 배웅 실비 패키지 - 해약환급금 - 전환 크레딧 결합 최종 순 절감액 산출 로직 설계
- [x] Task 5: 1:1 맞춤 영수증 좌우 대조 렌더링 스키마 확정
