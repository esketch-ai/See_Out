# Advisory & Architecture Board Governance
Status: Active
Owner: 강민석 박사 (총괄 지휘자)

## 1. 개요
'배웅(Bae-ung)' 플랫폼의 장기적인 아키텍처 일관성, 법적 무결성, 비즈니스 타당성을 보증하기 위해 30년 이상의 학술/산업계 경력을 보유한 최고 권위의 박사급 전문가 위원회를 구성하고 상시 거버넌스 체계를 가동한다.

## 3. 의사결정 프로세스
1. 모든 아키텍처 결정(ADR) 및 데이터 모델 변경은 관할 박사급 전문가의 검토 후 강민석 총괄 지휘자의 최종 승인을 거친다.
2. 모든 기획/설계 문서는 Themis AI PARA 원칙(`docs/_para/`)에 따라 누락 없이 지속적으로 자산화(Assetization)한다.
