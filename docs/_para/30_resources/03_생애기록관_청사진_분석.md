# 생애기록관 기획 및 실행 청사진 분석 리소스
출처: `docs/생애기록관_기획_및_실행_청사진.pdf`
정리 일시: 2026-09-26

## 1. 개요 및 비전
- **사후(Post-mortem) 중심의 한계 극복**: 장례는 평생 1~2회인 초저빈도 이벤트라 CAC가 극도로 높음.
- **생전(Pre-mortem) 일상 접점 확보**: '저장과 보관'을 매개로 한 일상적 Lock-in 형성. 일상적 구독이 장례의 CAC를 낮추고 투명한 장례가 다시 디지털 추모의 가치를 높이는 선순환 플라이휠 구축.

## 2. 생애기록관 핵심 가치
"내가 살아온 증거와 이야기의 안전한 보관"
1. **일기·수첩**: 페이지 스캔 및 검색용 문자 변환 (작성 시기, 공개 범위 설정).
2. **상장·자격증**: 수여 기관, 날짜, '본인에게 중요한 이유' 첨부.
3. **본인의 책·작품**: 권한 확인 후 디지털화, 창작 과정과 스토리 기록.
4. **사진·영상**: 원본 업로드 및 시기별/인물별/장소별 분류.
5. **물건·유품**: 다각도 촬영 및 음성 설명을 통한 의미 부여.
6. **평범한 일상**: 짧은 글과 음성 인터뷰 (취미, 음식, 관계 등).

## 3. 구독 요금제 및 비용 분리 원칙
- **월간 구독료(보관/관리)**:
  - 기록 보관 (Storage): 월 4,900원 (직접 업로드, 기본 검색, 보관, 내보내기)
  - 기록 정리 (Organization): 월 12,900원 (문자/음성 정리 초안 AI 생성, 추가 공간)
  - 기록 동행 (Companionship): 월 29,900원 (전문가 상담 및 정리 지원)
- **일회성 작업비 (One-off Costs, 철저 분리)**:
  - 방문 수거, 비파괴 스캔, 대면 인터뷰, 실물 기록집 제작 등.
  - "구독료보다 사람의 작업 시간 측정이 먼저다" -> 무제한 작업 절대 금지.

## 4. 물리적 유품 디지털 전환 7단계 프로토콜
1. 대상 선정 ➔ 2. 상태 기록(사진 촬영) ➔ 3. 인수/수거(방문촬영 우선) ➔ 4. 비파괴 작업 ➔ 5. 품질 검수 ➔ 6. 결과물 승인 ➔ 7. 원본 반환(인수확인서 서명)
- 실물 장기 보관은 초기 상품에서 제외.

## 5. 게이트키퍼(Gatekeeper) 사후 권한 및 보안 프로토콜
- "미접속 = 사망" 절대 불가 (사망진단서 및 유산관리자 접근키 필수 확인).
- 사후 데이터 처리 분기:
  1. 지정인 전달 (암호화 파일 이관)
  2. 일부 공개 (생전 승인 자료만 모바일 추모관 연동)
  3. 비공개 보존 (계약된 유예 기간 동안 비공개 유지)
  4. 기관 기증 (사전 수락 협약 완료 기관)
  5. 영구 삭제 (유예 기간 종료 후 완전 파기)

## 6. 1차 생애기록관 PoC 실행 계획
- **대상**: 유료 고객 20명 대상, 3개월간 밀착 운영.
- **프로세스**: 자료 10점 선택 ➔ 짧은 인터뷰 ➔ 연표/기록실 완성 ➔ 사후 설정 ➔ 월 구독 전환.
- **측정 지표**: 첫 기록 완성률, 다음 달 유료 유지율, 고객별 실제 작업 시간(원가 통제).
