## 💡 2. 개편 핵심 요구사항 (3대 원칙)

1. **톤앤매너 전환 (Dark ➔ Warm Light)**:
   - 기존의 무겁고 차가운 묵흑(블랙) 위주의 배경을 탈피.
   - **따뜻한 소프트 크림 & 아이보리 (`#FAF9F6`, `#FFFDF9`)** 베이스와 **온화한 세이지 그린 (`#19382C`, `#2D5A46`)**, **부드러운 앰버 골드 (`#C2A26A`)** 액센트 적용.
   - 유족이 방문했을 때 공포나 슬픔 대신 "마음 편히 기댈 수 있는 따뜻한 안도감"을 주는 채광 중심의 톤앤매너 유지.
2. **콘텐츠 다이어트 (텍스트 70% 축소)**:
   - 복잡한 산문 설명과 긴 줄글을 과감히 제거.
   - **직관적인 대형 아이콘 바**와 **2~3글자의 명사형 라벨**, **시각적인 3열 카드 타일**로 단순화.
3. **한국상조공제조합(KMACA) 구조 차용**:
   - 상단: 따뜻한 가족 비주얼 배너 ("함께라서 든든한, 따뜻한 배웅")
   - 중앙: 배너에 걸쳐진 **플로팅 5대 대형 퀵 아이콘 바**
   - 하단: **3열 분할 정보 구조** (미디어 영상 / 탭형 공지 / 3구 서비스 타일)

## 📐 3. 컴포넌트 레이아웃 및 세부 스펙

### [상단] 헤더 & 핫라인 바
- **로고**: 단정하고 따뜻한 '배웅' 한글 로고
- **GNB 메뉴**: 견적 진단 / 장례식장 찾기 / 정찰 패키지 / 이중안심 / 고객센터
- **우측 핫라인**: 눈에 띄는 폰트와 배경색으로 **`📞 24시간 상담 1588-XXXX`** 상시 노출

### [섹션 1] 메인 비주얼 배너 & 플로팅 퀵 메뉴 바
- **배너 영역**:
  - 은은한 자연광 속에서 미소를 짓고 있는 3대 가족의 따뜻한 사진
  - 메인 카피: **"함께라서 든든한, 따뜻한 배웅"**
  - 서브 카피: **"투명함이 가장 큰 위로가 되도록 — 알선 수수료 0원, 실시간 원가 공개"**
  - '서비스 안내 보기' 둥근 모서리 버튼
- **플로팅 퀵 메뉴 바 (5구 카드)**:
  - 1. 📊 **견적 진단**: 타 상조사 견적서 3초 OCR 판독
  - 2. 🏛️ **장례식장 찾기**: 수도권 동남부 38곳 실시간 공시비용
  - 3. 📦 **고정 패키지**: 280/390 무추가금 정찰제
  - 4. 🛡️ **이중안심(보호)**: 기존 상조 해약 위약금 100% 한도 보전
  - 5. 📞 **상담 전화 1588**: 원터치 즉시 통화 연결

### [섹션 2] 3열 분할 메인 콘텐츠 그리드 (KMACA 정통 차용)
- **열 1 (좌측, 미디어)**:
  - 숏폼/영상 스토리 카드: "마음을 전하는 이야기"
  - 시설 랜선투어 및 안심 서비스 영상 플레이어 (원형 Play 버튼)
- **열 2 (중앙, 탭형 공지/FAQ)**:
  - 2탭 구조: `[공지사항]` / `[자주 묻는 질문]`
  - 불필요한 내용 없이 **[카테고리 뱃지] + [제목] + [날짜]** 4~5줄만 깔끔하게 노출
  - 하단 '더보기 >' 링크
- **열 3 (우측, 3구 서비스 타일)**:
  - 타일 1: **서비스 신청** (손잡는 일러스트 + 바로가기 버튼)
  - 타일 2: **지원금 안내** (공제/바우처 혜택 안내)
  - 타일 3: **상담 센터** (전문 지도사 1:1 매칭)

## 🛡️ 4. 필수 작업 규칙 준수 (`AGENTS.md`)

seasnake 작업 시 아래 4대 규칙을 절대 위반하지 않도록 유의:

1. **타이포그래피 하한선 (N-7 규정)**:
   - 50~90세 노안 유족을 배려하여 **`text-xs` (12px) 완전 금지**.
   - 모든 텍스트는 최소 **`text-[13px]`** 이상, 본문은 `text-base` / `text-lg` 권장.
2. **텍스트 말줄임(`truncate`) 금지**:
   - `truncate` 대신 `break-words`, `min-w-0`를 사용하여 정찰 내역이 온전히 보이도록 처리.
3. **디자인 토큰 정본 준수 (`src/web/design-system/tokens.ts`)**:
   - 임의의 hex 색상 선언 금지. 토큰에 등록된 정본 컬러 사용.
   - 밝은 면(크림 `#FAF9F6`) 위 텍스트 대비비(4.5:1 이상) 준수 (`#151719`, `#42464E`, `#5A5E66`, `#19382C`).
4. **검증 실행**:
   - 작업 완료 후 반드시 `npm run verify` (TypeScript + Vitest 244개 + 실측 브라우저 감사)를 실행하여 `위반 0건` 확인.
